# vault-example

A fully **synthetic** vault (§8.5): 81 nodes and 6 episodes around a fictional
persona, safe to publish, regenerated by `bun scripts/gen-example-vault.ts`.
Do not put real personal data here — CI treats this directory as the only
place vault-shaped paths may exist in the public repo (§9.1).

It exists so that:

- `bun test` and `brain eval` run on a clean clone with zero setup
- retrieval quality has a measurable baseline (`queries.yaml`)
- the traversal invariants have deliberate structures to bite on:
  a 3-link `supersedes` chain (`jquery-prototype-ui` → `react-spa-frontend` →
  `htmx-server-rendered-ui`), two `contradicts` pairs, cross-cluster
  `mentioned_with` ties, and alias-only hits ("boris")

Open this folder as an Obsidian vault to see the graph.
